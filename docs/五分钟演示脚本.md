# 任务一五分钟演示脚本（CPU 阶段）

这份脚本可用于阶段汇报录屏。最终版需在云端 GPU A/B 完成后补充真实运行画面和原始结果；当前不能录制或宣称该部分已经完成。

## 0:00–0:40 任务与设计

展示更新版阶段汇报 PPT 第 1–2 页。说明每 16 个 token 一个逻辑块，页表将逻辑块映射到物理 KV 块；连续方案按最大长度预留，分页方案按生成进度扩页。

## 0:40–1:50 核心代码

打开 `kv_cache/allocator.py`，展示 `append_token`、`translate`、`fork`、`evict`。说明共享块的引用计数，以及部分末块写入时的复制。强调 CPU swap 当前只保存块元数据。

## 1:50–2:35 正确性验证

在项目根目录运行：

```bash
python -m unittest discover -s tests -v
python tests/measure_coverage.py
```

指出随机状态测试检查 500 步混合操作中的引用计数、GPU 帧唯一性和页表范围；覆盖率门槛为 70%。录屏时以现场输出为准，不预录固定数字。

## 2:35–3:45 量化实验

运行：

```bash
python run_experiment.py
```

展示 `results.csv`、`fragmentation.csv`、`long_context.csv` 和 `comparison.svg`。解释累计预留块需求、内部未用槽比例、时间加权块占用率和 OOM 失败率的不同含义。长上下文档位看 4096 token，指出逐步扩页可能在运行中失败。

## 3:45–4:30 GPU 验证计划

展示 `gpu_validation/bench.py --help` 与 `docs/云端GPU验证记录模板.md`。说明已选定真实引擎 A/B 加本项目仿真的验收口径，但云端实例、模型和实测输出尚未确定。最终录屏要替换此段，演示真实 GPU 的两组命令、输出 JSON 和图表。

## 4:30–5:00 结论与边界

CPU 仿真支持“按需分页减少预留浪费，并在当前合成负载下改善容量边界”的结论。真实 GPU 的吞吐、显存与 OOM 结论须等待实测；不同引擎的性能差异还包含调度和算子因素。
