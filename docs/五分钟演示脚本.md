## 0:00–0:35 目标与口径

说明任务只覆盖 KV Cache 分页内存管理子系统。每 16 个 token 对应一个逻辑 KV 块，页表映射到物理块；`L` 是 prompt 与生成 token 的总缓存长度。正式 CPU 合成负载的 prompt 占 `L` 的 50%。真实 GPU 验证采用同模型下的 Transformers StaticCache 与 vLLM 引擎 A/B，并用本项目 CPU 仿真器验证分页机制。

## 0:35–1:25 核心实现

打开 `kv_cache/allocator.py`，展示 `BitmapFramePool`、`PageTable`、`append_token`、`fork`、`evict`、`translate`。解释位图记录每帧状态，空闲栈使固定块取还为 O(1)；单层稀疏字典页表仅保存已映射的逻辑块。说明前缀共享和 COW 通过引用计数保证独占写入。CPU 换出目前只模拟块元数据，不搬运真实 KV 张量。
